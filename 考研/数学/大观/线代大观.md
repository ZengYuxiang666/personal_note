# 线代大观


### 特性

- 题目说某个矩阵一行只和为固定的数，忍不住就要对这个矩阵乘全1向量
    - 可得到特征值，特征向量
- A的行列式为0时，有$AA^{*} = A^{*}A = 0$，A或$A^{*}$中每个列向量均为另一个的解向量
- A、B是实对称则 A的转置、A+B、A方、A的n次方、A的逆、$AA^{T}$、$A^{T}A$、A的多项式、经过合同变换 都是实对称
    - 其中$AA^{T}$、$A^{T}A$  原本A不是实对称这个也还会是实对称矩阵
- 3阶A的特征值为a,b,c，则A的伴随的特征值为ab、ac、bc 这个结论在A可逆不可逆都成立
    - 4阶也类似，n阶也类似，无论是否可逆
- 看到一个矩阵做初等变换变成另一个矩阵，则将另一个矩阵写成乘了初等矩阵的形式
- 单位向量的内积为1，可用上秩1结论（矩阵有1这个特征值）
- 看到题目给了矩阵，或者关系式，忍不住就想要拆
- 告诉你一个非齐次的特解、有可能是暗示你特征值和特征向量。而告诉你通解则是告诉你特征值为0和特征向量
- 告诉你AB=0则是暗示你B中的每个列向量都是A的解向量，      R(A)+R(B) 小于等于N
- 要求矩阵的特征值和特征向量时，可尝试将矩阵分解成             秩1矩阵 + kE
- A11不为0，可得到其他列向量线性无关
- 正交矩阵，每个列向量的平方为1，每两个不同列向量相乘为0
- 求特征值前先看看能不能分解，特别是主对角线带参数，特征向量就是被拆出来的矩阵的特征向量
- A，B相似，定参数，trA=trB，A的行列式=B的行列式
- A是正交矩阵则A的转置、逆、伴随都是正交矩阵
- b的转置乘a等于0，是告诉你a与b垂直
- A为方阵时，R(A) = k，则Ax = 0 有n-k个解向量，R(A-aE)=k，则A的特征值为a，有n-k个特征向量
- 看到两个向量内积为0，立马想到这两个向量垂直
- 求特征值时，可将矩阵分解，判断两矩阵是否相似时，可用分解后的矩阵判断
- 看到AB=C，立马想到B中的向量是否为A的特征向量
- 看到一个矩阵等于两个秩1矩阵相加，忍不住就想到两个矩阵秩必小于3，必有0特征值
- 看到f(A)立马就要想到特征值
- 给个等式，证明两个矩阵可交换
    - 将矩阵配好，证明配好的矩阵可逆，再交换换回来
