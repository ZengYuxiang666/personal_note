当 $\lim_{n\rightarrow \infty}|a_n| = 0$ 时 $\lim_{n\rightarrow \infty}a_n = 0$ 
若要证$\lim_{n\rightarrow \infty}a_n = 0$ ，可以转化成证$\lim_{n\rightarrow \infty}|a_n| = 0$ ，由于$|a_n| >= 0$，则使用夹逼准则时只需要找到一个数列 ${b_n}$ 满足 $|a_n| <= b_n$，且$\lim_{n\rightarrow \infty}b_n = 0$即可

##### 夹逼准则的放缩法：

###### 1.简单的放大与缩小：

$n * u_{min} <= u_1 + u_2 + ... + u_n <= n*u_{max}$
$1 * u_{max} <= u_1 + u_2 + ... + u_n <= n*u_{max}$

###### 2.利用重要不等式：

$|a\pm b| <= |a| + |b|$               $||a|-|b|| <= |a-b|$

$\sqrt{ab} <= \frac{a+b}{2} <= \sqrt{\frac{a^2+b^2}{2}}$

$\sqrt{abc} <= \frac{a+b+c}{3} <= \sqrt{\frac{a^3+b^3+c^3}{2}}$

$sinx < x < tanx$   当$({0 < x < \frac{\pi}{2}})$        $sinx < x$  当 $(x > 0)$

$x < tanx < \frac{4}{\pi}x$   当  $(0 < x < \frac{\pi}{4})$

$sinx > \frac{2}{\pi}x$   当$(0 < x < \frac{\pi}{2})$

$arctanx <= x <= arcsinx$  当$(0 <= x <= 1)$    可考 $x_{n+1} = arctanx_n < x_n$    故{$x_n$}单调减少

$e^x >= x + 1$  任意x

$x - 1 >= lnx(x>0)$

$\frac{1}{1+x} < ln(1+\frac{1}{x}) < \frac{1}{x}\ \ \ 当(x>0)$     利用中值定理得到

$\frac{x}{1+x} < ln(1+x) < x\ \ \ \ 当(x>0)$       利用中值定理得到

3.利用闭区间上连续函数必有最大值与最小值

4.利用压缩映射

##### 证明数列收敛：

1.先证数列存在极限
上面的都是证明数列存在极限的方法

2.证明数列单调
(1)$求x_{n+1} - x_n$
(2)求$\frac{x_{n+1}}{n}$
(3)求$x_{n+1} = f(x_n)$的导数
	假如导数大于0，则看$x_1与x_2$的大小关系，可以确定是单调递减还是递增
	假如导数小于0，则不能确定


3.得到数列极限存在，直接用$a_{n+1} = a_n$带入题目条件求得极限

---

在作为$lim_{n\rightarrow \infty} = a$的充要条件中，不能对收敛速度有要求。例如$|x_n - a| <= \frac{1}{n}$是数列${x_n}$收敛于a的充分不必要条件
