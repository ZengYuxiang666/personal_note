## 代码注意事项
- 分清楚结构体和结构体指针的区别，他们取元素的区别，放在函数参数的区别，返回时的区别
- malloc返回的是首地址，所以只能强转成指针变量（结构体指针），不能强转成结构体，当然强转时用typedef后的指针声明可以不用加*号 例 tpyedef **node nodelink
- 搞清楚数组放在函数参数中怎么写，怎么定义结构体数组、结构体指针数组，他们赋值时有什么区别

    - 结构体已经分配了一块内存了，而结构体指针最终是要指向一个具体的结构体的

        - i，j初始值为1
            - next[j] = 下标j以前的串的最长公共前缀加1
            - next[0]固定为0
            - 最长公共前缀长度不能覆盖前面的整个串                                比如aaaa，next[4] = 2+1 = 3
            - 匹配失败且next[j] != 0时，i不动，j = next[j]
            - 匹配失败且next[j] = 0时，i++，j = 1
        - i，j初始值为0
            - next[j] = 下标j以前的串的最长公共前缀(不需要加1)
    - 4.2.3 KMP算法的进一步优化(P117)
        - 手算next_val数组
            - 写出next数组
            - 初始化next_val[1] = 0
            - 从j=2开始，看s[2]和s[next[2]]，如果相同，则next_val[2] = next_val[next[2]]   如果这次比较的字符与将j更新后比较的字符相同，则将next_val值改成 下一个j的next_val的值
